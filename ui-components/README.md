# UI Components

Keep reusable UI components small, focused, documented, and consistent with the app's existing UI stack.

- Compose projects: prefer stateless composables with state hoisted where practical.
- XML/View projects: use reusable layouts, styles, and custom views only when they simplify maintenance.
- Include previews or sample layouts where supported.
- Provide content descriptions for meaningful icons and images.
- Avoid introducing a new UI framework without checking project compatibility and user approval.
