# Design System

Document each app's colors, typography, spacing, shapes, elevation, icon style, and light/dark themes before building screens.

## Guidelines
- Establish reusable design tokens instead of scattering raw values through screens.
- Maintain contrast and readable type sizes.
- Define responsive behavior for small and large screens.
- Keep components visually consistent across loading, error, empty, and normal states.
- For Material guidance, consult https://m3.material.io/.
