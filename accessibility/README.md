# Accessibility

- Give meaningful controls accessible names and useful content descriptions.
- Ensure interactive elements are reachable and operable without precise gestures.
- Maintain sufficient contrast and support font/display scaling.
- Do not communicate status by color alone.
- Provide clear validation messages and focus behavior.
- Test with TalkBack and Android accessibility tools when possible.
- Prefer platform accessibility semantics over custom behavior that hides information from assistive technology.
