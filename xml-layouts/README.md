# XML Layouts

- Use meaningful IDs and resource names.
- Put user-facing strings in string resources; avoid hard-coded text in layouts.
- Reuse dimensions, colors, styles, and themes.
- Support accessibility, scalable text, and different screen sizes.
- Avoid deeply nested layouts when a simpler layout works.
- Check AndroidManifest.xml and theme compatibility before adding components.
- Do not mix Compose and XML without a clear project reason.
