# Java Rules

- Follow the project's existing Java style and supported language level.
- Use clear names, small methods, and explicit error handling.
- Avoid blocking the main thread with network, file, or database operations.
- Close resources reliably; prefer try-with-resources where applicable.
- Validate external input and handle null values deliberately.
- Keep business logic out of Activities and UI controllers where practical.
- Do not convert Java to Kotlin automatically unless requested.
